# Istagrammo, an Instagram Clone
Istagrammo is an Instagram Clone built with flutter + firebase, the software includes:
- **Authentication**, email, password or Google Authentication
- **Upload new posts or tweets**
- **Adding comments**
- **Edit profile**
- **Follow users**
## App Pages
The app is three page based:   
- **Home page** too see posts
- **Search page** to search users
- **Profile page**

I used provider and listeners: **user_provider** for user data and **theme_provider** for toggle light/dark app theme
